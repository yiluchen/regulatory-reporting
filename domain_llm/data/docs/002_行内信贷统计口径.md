# 行内信贷统计口径说明（示例）

> 本文为示例文本，用于演示行内口径与监管口径的差异，不构成真实制度。

## 第一章 逾期口径

第一条 逾期天数采用自然日口径，起算日与监管口径保持一致，即到期日次日。

第二条 逾期账龄按月末最后一日余额划分区间，与监管按每日余额划分的统计方式不同，月度报表以本口径为准。

第三条 单笔贷款逾期超过 90 天的，风险分类至少下调为次级。

## 第二章 报表口径

第四条 报表字段命名以行内指标台账为准，同一指标在不同报表中的名称必须保持一致。

第五条 金额类指标统一保留两位小数，比例类指标保留四位小数。

第六条 机构维度按一级分行汇总，二级分行数据并入所属一级分行。
